# 第二轮：文献核验、检索效率和运行控制

日期：2026-10-14

## 已实现

### 1. 文献身份与正文分开判断

- 一次读取 PDF 形成前三页证据，避免原校验流程重复打开文件三次。
- 拼接跨行题名、处理孤立连字符、HTML 实体和连字；文件名优先使用原引用题名。
- 使用本篇首页/元数据中的 DOI 和专利公开编号，不使用参考文献列表中的标识或后续正文中的引用题名确认身份。
- 处理专利编号排版空格、标点及前导零。专利标题提取混入分类信息时可由公开编号确认。
- 轻微拼写容错要求额外的作者/年份吻合；不会把数字变化当作拼写错误，也不降低全局标题阈值。标识或题名数值冲突保留待复核文件。
- 把明显的补充材料、预览、仅摘要文件排除出正文成功；扫描件、空白件、提取证据不足等标记 `needs_review`，不冒充已确认正文。
- 明确引用演讲、教程时允许对应原始演讲 PDF；不能把幻灯片自动当成普通论文正文。
- 单篇、批量及 GUI 重命名使用相同的判断逻辑。关闭题名核验时仍检查文档类型。

### 2. 分阶段检索与缓存

- 元数据/高收益开放版本优先，每阶段有新候选就尝试；得到合格正文立即停止后续来源。
- 生物医学、化学、图书、经济学来源按引用线索选择。这个路由是启发式，并非完整的学科分类器。
- 记录已尝试候选，避免不同阶段重复访问同一候选地址；待复核件不阻止继续寻找更可靠的全文。
- 来源级缓存分开保存，默认有效结果 7 天、空结果 15 分钟。401/403、限流、服务器/网络错误及 JSON 解析异常不缓存成永久缺少全文。
- 每条检索有默认 90 秒的阶段间软预算；不会强制中断已发起的请求，单次网络操作仍受 HTTP 超时控制。
- 批量请求的并发/间隔限制覆盖真正请求的主机、重定向和站点内部请求。连接体消费或关闭后才释放名额；429/503 按 Retry-After 退避。每阶段结束关闭 Session。

### 3. 进度保存与取消

- 每条任务完成或失败，即原子更新清单和日志。
- 保存的是已完成条目的独立快照，不把其他线程正在修改的数据写成完成状态。
- 同次运行复用已完成文件的哈希，最终仍重新核对；强制关闭可恢复最后已保存的完整条目，在途任务可重试。
- 只保持有限数量的已提交任务，停止后不继续提交后续条目；限速、重试等待可取消，文件流在下一次读取检查取消信号。
- GUI 从管线直接接收实时进度，不再劫持全局标准输出。停止、完成、异常分别报告。
- 停止不是强制杀死线程：当前 DNS/网络读取或 PDF 解析需要返回、到达检查点或超时，才能完成收尾。

### 4. 并发文件保护

- 下载落盘、校验后重命名、归档/待复核移动都拒绝覆盖已有目标。
- 并发测试曾发现 Windows 占位文件替换方式会发生共享冲突。现在 Windows 使用拒绝覆盖的原子重命名；同输出卷的 POSIX 路径采用独占链接发布。
- 保留原文参考文献编号，同名增加后缀；失败不会删除旧 PDF。状态与缓存写入使用临时文件替换。

## 实测结果

最终验收：**329 项项目测试通过（其中第二轮新增 45 项），5 项原适配器兼容性测试通过**。语法编译、三个命令行入口帮助启动、Git 补丁格式检查均通过。

- 项目测试包含新增的第二轮回归用例：标题、正文类型、标识/数字冲突、来源短路、缓存到期、临时错误、逐条检查点、取消、GUI 实时回调、每域单并发、并发重命名和旧记录重新核验。
- 使用真实 requests/urllib3 与仅绑定本机回环地址的临时 HTTP 服务，验证了“重定向→HTML→PDF”，每域并发为 1 时正常完成、没有死锁。没有请求出版社。
- 对此前人工核验的 50 个 PDF，只读执行新核验：**49 个自动确认，1 个扫描版专利待复核，0 个被判错文献/非正文；全部文件 SHA-256 不变。**
- 此前工具误拒绝的 10 个文件中，**9 个现在自动确认，[39] 保留为待复核**。没有为了让扫描件通过而虚构 OCR 结果。
- 真实文件检查使用整理清单中的引用及已核验 DOI；不是重新对原始论文的 78 条引用进行出版社联网下载，也不表示新增下载了 49 篇。
- 全套测试、原下载适配器兼容性、语法编译、入口启动和补丁格式的最终结果见此次交付说明。

没有读取真实 Cookie，没有修改先前下载的论文，没有增加第三方依赖；保留第一轮修改。尚未重建可执行安装包，使用旧打包 EXE 时需要重新打包才能获得源码改进。

## 输出和兼容性

- `needs_review`：保留文件，但不计入正文下载成功；主要存放在 `downloads/review_pdfs`。
- `document_kind`：如 `full_text`、`presentation`、`supplementary`、`preview`、`abstract`、`unknown`。
- `verification_reason`：正文证据、扫描/空白、标识冲突等具体原因。
- `verification_version`：当前为 2；旧记录在下载流程中重新检查，不必删除旧清单。
- `identity_checked`：是否启用了文献身份核验；再次启用核验时会重查此前未核验记录。
- 原 JSON 字段和 CSV 前七个字段保留，新增字段追加。原编号不变。

## 仍有边界

- 未接入 OCR；扫描件需要人工核对，后续可另行增加可选 OCR。
- 分类并不保证识别所有特殊版式、缺页、伪装预览或无明显标签的补充材料；不能把自动通过当成绝对完整性证明。
- 尚未做真实出版社登录/下载测试、原始 78 条完整流程对照测速、GUI 窗口点击验收或重新打包 EXE。
- 未增加所有未知站点的通用网页后备解析，也未重做双栏参考文献提取。
- 断点恢复针对已写入的完整条目，不恢复单个 PDF 中断前的字节偏移；磁盘不可写或进程在首次状态写入前被杀死不可能保证保存新进度。

这些限制已明确保留，不以放松校验或增加线程掩盖。
